2026-09-07 — The phantom "Asr" notification

  • Some iOS users were getting an extra "Asr" alert at odd hours, sometimes at night. The cause was a leftover test notification from development that fired two minutes after every app launch. Removed it: prayer-time-lk#16 and prayer-time-se#21.
  • Then read the whole notification path end to end and wrote up everything else that was wrong with it — a debugging session where the bug you were sent to fix turns out to be the tip of it.

2026-09-05 — A Qibla compass, on both sites

  • Both prayer-time sites have a real Qibla compass now, replacing the "coming soon" page: prayer-time-lk#15 (English) and prayer-time-se#20 (Swedish).
  • The bearing is the same great-circle formula the native apps already use, unit-tested against published qibla tables: London 118.99, Stockholm 148.23 and Kiruna 155.16 degrees all matched to the hundredth.
  • The tricky part was never the math but the phone: iOS Safari hides its compass behind a one-tap permission button, Android streams absolute heading events (gyro drift has to be ignored), and a desktop browser has no magnetometer at all.
  • Redrew the dial to match the native app after the first version's needle rendered off-centre — a reminder that a rotation pivot is not always where you think it is.
  • Lesson: you can unit-test compass math in a sandbox, but not a phone's magnetometer. These pages shipped with verified math and an honest request to try them on a real device — some bugs only live between a sensor and a hand.

2026-09-03 — Caching on, and a lesson in ETags

  • Edge caching for the full-year prayer-times endpoints is live on both APIs: repeat syncs now hit the edge and skip the database entirely.
  • Byte-compared live payloads against the source data across several cities — 365 days each, zero mismatches — and invalid cities or methods now return a clean 404.
  • A post-deploy oddity taught me something: two identical responses briefly carried different validators (ETags) while the edge cache filled twice during rollout. Harmless, and it self-healed within a day.

2026-09-02 — From a scan to a lookup

  • Added an index on the times table by city: each full-year lookup went from a ~10,000-row scan to roughly 360 rows — and zero rows once a response is cached.
